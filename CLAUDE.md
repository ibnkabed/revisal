# Revisal

A free, open-source iPhone app for students (public repository `ibnkabed/revisal`, MIT), built from the public Gradal (`C:\Users\abdul\Documents\My Projects\المدرسة\Gradal\Gradal-Public`) without its paper side. Three parts: «المنهج» (named in the singular since 2026-11-02; the student adds any curriculum or a summary of it as a PDF, names its units by pages, and reviews a unit with «اختر الإجابة الصحيحة» questions written by AI with the student's own free key), «التحصيلي» and «القدرات» (question banks bundled in the app, no AI, no internet). Everything is solved on the phone; no printing, no A4, no answer sheets, no students. The owner will offer it to the education administration as open source.

This file alone holds the instructions of both agents in the project: Claude reads it directly, and Codex through its fallback setting. So no `AGENTS.md`, no `AGENTS.override.md` and no import line (`@ملف`) is created. What concerns one agent only is written in the section «خاص بـ Claude» or «خاص بـ Codex». The general rules for all projects are in the global file, so they are not repeated here.

## Project rules

- **The owner's decisions (2026-11-01):** every question is «اختر الإجابة الصحيحة» with exactly four options; 1 to 10 questions per review; the model, not the student, decides each question's section, skill or style, writes it under the question, and more questions mean more kinds until the whole unit is covered; «حدّث» brings ten (or the chosen count) new questions with their skills; no question carries a written explanation: under every question, bank or المنهج, a «اشرح لي» button asks the student's own linked provider once and keeps the reply on the phone (owner, 2026-11-02; it replaced the explanation written with each curriculum question).
- **The banks are a question bank, not runtime AI** (owner, 2026-11-01): `bank/tahsili.json` and `bank/qudurat.json` are built on the PC from the owner's PDFs (the last step, after everything else is ready), with every question of every file: its text, four options and the right answer only, no explanation (owner, 2026-11-01: «نلغي موضوع الشرح لأنه سيعقد الأمور وسيثقل العمل»), and bundled in the IPA. The app draws every question once before any comes again (`Bank.draw`). The format and its checks are in `docs/BANK.md`; `RevisalCheck --bank-check bank` must pass before a bank ships. The source PDFs stay in `المصادر/`, outside Git. The owner's Qudurat source is a Drive folder that the education administration updates weekly (link in `docs/BANK.md`).
- **Distribution is Sideloadly with an unsigned IPA from GitHub Actions** (owner, 2026-11-01), exactly as Gradal: `.github/workflows/build-ipa.yml` checks the rules and builds `Revisal-unsigned.ipa`; a tag `v*` attaches it to a Release.
- **The app is public and specific to no one:** no owner names, no Gradal, ZipGrade, Noor, تحاضير مدرستي, حارس المشروع or school letterhead. AI keys are the student's own, pasted in the settings and kept in the Keychain (the same exception as the public Gradal: the phone calls the providers directly, not the guardian's gateway).
- **Shared code with the public Gradal** is a copy, not a link: `AI/` (providers, client, Keychain), `Book/BookText.swift` and `BookRules`, `Backup/`. A fix in one is checked in the other in the same session.
- **Pure rules stay Foundation-only** (`Model/Models.swift`, `Review/ReviewRules.swift`, `Review/Pattern.swift`, `Book/BookRules.swift`, `Bank/Bank.swift`), because `RevisalCheck` compiles them on macOS in CI; a new rule gets a check in `ios/RevisalCheck/main.swift`.
- **Git (owner, 2026-11-02: a normal open-source project, public only):** the remote `origin` is the public `ibnkabed/revisal`, where finished and checked work is pushed directly and CI runs free; it is the only repository: the old private copy `ibnkabed-private/Revisal` was deleted by the owner on 2026-11-02, after all its work was in the public one. The folder is excluded from the School repository (`/Revisal-Public/` in its `.gitignore`; the folder was `Revisal/` until 2026-11-02). Only a Release (a `v*` tag with the IPA and the «تواصل» text) waits for the owner's request.
- **Revisal is outside the project guardian (owner, 2026-11-02):** the guardian does not commit, push, back up or check it, because it has no tie to this public app. So nothing saves the work by itself: the session commits finished, checked work and pushes it to the public `origin`, and keeps `backups` as the only copy rule says.
- **Releasing the IPA follows the public Gradal exactly (owner, 2026-11-02):** a public repository `ibnkabed/revisal` with an Arabic description and tuned topics (hashtags), the unsigned IPA attached to a GitHub Release from a `v*` tag, and a ready-to-copy text for the education administration's «تواصل» system: a title of at most 100 characters and a subject of at most 1000 characters, counted before handing over (as was done for Gradal in the window «Gradal: تطبيق تصحيح الاختبارات»). Done only when the owner asks for the release.
- **`README.md` is updated with every change,** in the same save: every feature or decision is a line in it, and every new folder is a line in «## خريطة الملفات» with its class.
- **The one backup is in `backups`,** excluded from Git, and no copies elsewhere.
- **The long detail is in `docs`:** `docs/DATA.md` (what the phone stores), `docs/BANK.md` (the bank format and how it is built).
- **README additions go at its end, dated — never in the middle (owner, 2026-10-31, mandatory):** every new feature, decision, change or fix in this project is appended as a dated line or block at the very bottom of `README.md`. The guardian reads README from the last line upward until it reaches the lines it already checked, and judges the project from those new lines, which is more accurate and cheaper than rereading the whole file. Only two in-place edits are allowed: a line in «## خريطة الملفات» (the guardian reads that section mechanically), and correcting text that became false — and that correction is also logged with a dated line at the end.
